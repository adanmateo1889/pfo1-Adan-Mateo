Landing page realizada para la **Práctica Formativa Obligatoria 1 (PFO1)** de la Tecnicatura en Desarrollo de Software.

## 🎨 Decisiones de diseño

Para el diseño elegí un fondo oscuro y usé verde agua como color principal para algunos detalles. Me gustó esta combinación porque genera un buen contraste y le da a la página un estilo relacionado con la tecnología.

Usé **CSS Grid** principalmente para organizar las partes que tienen varias columnas, como la presentación inicial, las habilidades, los proyectos y la sección de contacto.

También usé **Flexbox** para organizar elementos más simples, por ejemplo el menú de navegación, los botones, algunas etiquetas y el footer.

Para que la página se pueda ver bien en diferentes tamaños de pantalla utilicé medidas relativas, `clamp()` y media queries. De esta manera, cuando se abre desde una tablet o un celular, las columnas se acomodan y el contenido sigue siendo fácil de leer.

Para las tipografías elegí **Space Grotesk** en los títulos e **Inter** para el resto de los textos. Además, utilicé variables CSS para guardar colores y otros estilos que se repiten, así resulta más sencillo mantener el mismo diseño en toda la página.

## ♿ Accesibilidad

También intenté tener en cuenta algunos aspectos de accesibilidad que podía aplicar en el proyecto:

- agregué un enlace para saltar directamente al contenido principal;
- la imagen utilizada tiene texto alternativo con `alt`;
- los campos del formulario tienen su correspondiente `label`;
- relacioné los `label` con los campos usando `for` e `id`;
- agregué foco visible en campos y controles;
- utilicé `aria-label` en algunos elementos de navegación;
- traté de mantener un buen contraste entre el fondo y los textos;
- agregué `prefers-reduced-motion` para reducir las animaciones cuando el usuario tiene configurada esa preferencia.
